# vortextech-cybersec-week4
 Week 4: Mini Incident Response Plan
What this is
This repository contains a mini incident response plan written for a hypothetical data breach scenario, completed as the final deliverable for Week 4 of the Vortex Tech Cyber Security Internship Track.
The scenario: a fictional e-commerce company, Meridian Retail Co., exposes customer order data (names, addresses, emails, partial payment card digits) through an unsecured API endpoint that was missing an authentication check after a service migration. The plan walks through how the incident would realistically be detected, contained, eradicated, and recovered from, using the NIST SP 800-61 Incident Response Lifecycle (Preparation → Detection & Analysis → Containment → Eradication → Recovery → Post-Incident Activity).
What's in this repo
INCIDENT_RESPONSE_PLAN.md — the full incident response plan, including:
The breach scenario
Each NIST IR phase applied to the scenario
An internal communication plan (who is notified, and when)
Three preventative measures tied to the root cause
How to "run" it
There's no code to execute — this is a written planning document. To review it:
Open INCIDENT_RESPONSE_PLAN.md in this repository (renders directly on GitHub) or in any Markdown viewer.
Read top to bottom; it's organized by IR phase in the order a real response would follow.
